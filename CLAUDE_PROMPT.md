# Задание для Claude: исправить результаты ревью MyHotkey

Прочитай полностью `CLAUDE.md` и `CODE_REVIEW.md` в корне репозитория
MyHotkey.

Проверь каждую находку `CODE_REVIEW.md` по текущему коду и исправь
подтверждённые проблемы. Не ограничивайся отчётом или планом — реализуй
исправления.

## Приоритет

1. Закрой Critical-границу привилегий. Обычный medium-integrity процесс не
   должен использовать elevated-движок для запуска команд или управления
   elevated-окнами. Не считай проверку SID достаточной защитой. Сохрани быстрый
   запуск и удобство продукта, но сначала обеспечь корректную security model и
   задокументируй её.
2. Вынеси low-level hook на выделенный поток; тяжёлые действия и IPC должны
   выполняться вне него.
3. Исключи выполнение action по устаревшему индексу после reload — используй
   generation ID или безопасный immutable snapshot.
4. Исправь потерю настроек при нескольких UI/внешнем редактировании и обработку
   atomic replace.
5. Исправь утечку памяти при ошибочном `parse_action`.
6. Корректно обработай capture timeout и disconnect в UI.
7. Отклоняй повторяющиеся или конфликтующие modifier groups.

## Требования

- Сохрани разделение на лёгкий нативный engine и WPF UI по требованию.
- Не выполняй тяжёлую работу в hook callback или его message-loop потоке.
- Добавь тесты для каждого исправленного дефекта: config errors/reload, stale
  actions, duplicate modifiers, IPC/capture state и конфликты сохранения там,
  где это практически возможно.
- Не заменяй существующую подключённую иконку. Альтернативный вариант
  `assets/myhotkey-remap-icon-codex.png` оставь отдельным.
- Собери engine с `-Wall -Wextra`, собери WPF UI и прогони все тесты.
- Следуй правилу `CLAUDE.md`: одно логическое исправление — один отдельный
  коммит.
- После завершения обнови `CODE_REVIEW.md`: пометь исправленные пункты, укажи
  коммиты и оставшиеся риски.
- В финале перечисли изменения, тесты, коммиты и всё, что осталось нерешённым.
