# MyHotkey

Переназначение клавиш для Windows. То же, что делает AutoHotkey, но настраивается
мышкой и стартует мгновенно.

## Почему

AutoHotkey требует читать мануал и писать код на своём языке, а на автозагрузке
тащит рантайм и парсер скрипта — отсюда заметная пауза после логина, пока хоткеи
ещё не работают.

Здесь это разделено на два процесса:

```
myhotkey-engine.exe    чистый Win32 на C, без рантайма, ~60 КБ
                       стартует при логоне, висит в трее
                       low-level hook + движок правил + config.json

myhotkey-ui.exe        запускается по требованию, из трея
                       редактор правил; на автозагрузку не влияет
```

Движок ничего не знает про UI, UI ничего не знает про клавиатуру. Общаются через
`config.json` и именованный канал.

## Состояние

Готов движок. UI ещё не написан — пока правила редактируются в `config.json`,
движок перечитывает файл сам, сохранять и перезапускать ничего не надо.

## Сборка

Нужен C-компилятор из Visual Studio Build Tools и Windows SDK.

```
build.bat
```

Результат — `build\myhotkey-engine.exe`, один файл без зависимостей.

## Конфигурация

`%APPDATA%\MyHotkey\config.json`, создаётся при первом запуске.

```json
{
  "version": 1,
  "rules": [
    {
      "id": "caps-layout",
      "name": "CapsLock переключает раскладку",
      "enabled": true,
      "trigger": "CapsLock",
      "on": "release",
      "action": { "type": "combo", "keys": ["Ctrl+Shift"] }
    },
    {
      "id": "alt-s-back",
      "name": "Alt+S — назад",
      "trigger": "Alt+S",
      "action": { "type": "combo", "keys": ["Alt+Left"] }
    }
  ]
}
```

### Поля правила

| Поле      | Значение                                                          |
|-----------|-------------------------------------------------------------------|
| `trigger` | Сочетание: `CapsLock`, `Alt+S`, `Ctrl+Shift+F1`. Обязана быть настоящая клавиша, одни модификаторы не годятся. |
| `on`      | `press` (по умолчанию) или `release` — сработать на отпускании.    |
| `enabled` | `false` временно выключает правило, не удаляя его.                 |
| `app`     | Работать только в этом процессе, например `chrome.exe`.            |
| `notApp`  | Работать везде, кроме этого процесса.                              |
| `action`  | Что сделать, см. ниже.                                             |

### Действия

| `type`   | Поля                  | Что делает                                   |
|----------|-----------------------|----------------------------------------------|
| `combo`  | `keys`: список аккордов | Отправить сочетания по порядку.            |
| `text`   | `text`                | Напечатать строку (юникод, раскладка не важна). |
| `launch` | `path`, `args`        | Запустить программу или открыть URL.         |
| `layout` | `direction`           | Сменить раскладку напрямую, `next` или `prev`. |
| `block`  | —                     | Проглотить клавишу и ничего не делать.       |

### Имена клавиш

Буквы и цифры сами собой: `A`, `7`. Дальше `F1`–`F24`, `CapsLock`, `Tab`, `Enter`,
`Esc`, `Space`, `Backspace`, `Delete`, `Insert`, `Home`, `End`, `PageUp`, `PageDown`,
`Left`, `Right`, `Up`, `Down`, `Numpad0`–`Numpad9`, медиа-клавиши.

Знаки препинания — словами, чтобы `+` не путался с разделителем: `Minus`, `Equals`,
`Comma`, `Period`, `Slash`, `Semicolon`, `Quote`, `Backtick`, `LBracket`, `RBracket`,
`Backslash`.

Модификаторы: `Ctrl`, `Alt`, `Shift`, `Win`.

## Автозагрузка

Папка «Автозагрузка» запускает программы в самом конце входа в систему — ровно та
задержка, из-за которой AutoHotkey «просыпается» не сразу. Планировщик задач с
триггером «При входе в систему» срабатывает заметно раньше, а флаг наивысших прав
вдобавок даёт перехват клавиш в окнах с повышенными привилегиями:

```
schtasks /create /tn MyHotkey /tr "C:\путь\myhotkey-engine.exe" /sc onlogon /rl highest /f
```

## Что перехватить нельзя

Ctrl+Alt+Del и Win+L обрабатываются ядром и защищённым процессом winlogon. Ни один
инструмент в пользовательском режиме их не видит — это ограничение Windows, а не
приложения.
